## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Cybergoul/git-test-project
cd git-test-project
```

### 2. Check the current branch

```bash
git branch
```

### 3. Make a change and push it

```bash
git add .
git commit -m "Describe your changes"
git push
```

## 📚 Key Git Commands

| Command | Description |
|---|---|
| `git status` | Check the current state |
| `git add .` | Stage changes |
| `git commit -m "message"` | Save a commit |
| `git switch -c feature-name` | Create and switch branches |
| `git push` | Upload commits |
| `git pull` | Fetch and integrate remote changes |
